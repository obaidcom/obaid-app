# متجر عبيد الإلكتروني

متجر عربي RTL مبني باستخدام Next.js App Router وTypeScript وTailwind CSS v4 وshadcn/ui وRadix UI وFramer Motion وLucide React وnext-themes وخط Cairo.

## التشغيل
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

## ميزات الواجهة الحالية
- بحث وتصنيفات للمنتجات.
- سلة تفاعلية مع الكميات والحذف.
- المفضلة والملف الشخصي وواجهة إتمام طلب تجريبية.
- سلايدر وحركات انتقالية وتصميم متجاوب للهاتف والكمبيوتر.
- العملة المعروضة: الليرة السورية (ل.س).

## خطة الميزات التجارية
- حسابات العملاء والعناوين وسجل الطلبات.
- لوحة إدارة المنتجات والأسعار والمخزون والطلبات.
- كوبونات وعروض وتقييمات المنتجات.
- الشحن حسب المحافظة.
- الدفع عند الاستلام وطرق الدفع المحلية اليدوية بعد إعداد بيانات التاجر.
- قاعدة بيانات آمنة بصلاحيات RLS.

راجع `SUPABASE_SETUP.md` و`supabase/schema.sql` لإعداد قاعدة البيانات. إضافة مخطط SQL وحدها لا تربط الواجهة تلقائياً؛ يجب إعداد مشروع Supabase وربط الواجهة واختبارها قبل استخدام المتجر في معاملات حقيقية.

## ملاحظة الدفع
شام كاش وسيريتل كاش وMTN كاش والتحويل البنكي خيارات يدوية مقترحة للسوق السوري؛ لا يتم تأكيد أي تحويل تلقائياً، ولا تعرضها كخدمات مفعّلة قبل إدخال بيانات التاجر والتحقق من شروط المزوّد.
