# متجر عبيد الإلكتروني

واجهة متجر عربية RTL مبنية باستخدام Next.js App Router وTypeScript وTailwind CSS وواجهات على نمط shadcn/ui وFramer Motion وLucide React.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## المزايا

- تصميم متجاوب للهاتف والكمبيوتر مع الوضع الداكن والفاتح حسب إعداد الجهاز.
- بحث وتصنيفات للمنتجات وبطاقات تفاعلية ومفضلة.
- سلة مشتريات مع تغيير الكميات وحذف المنتجات.
- ملف شخصي ونموذج طلب تجريبي بالدفع عند الاستلام.
- حفظ السلة والملف الشخصي والطلبات محلياً في المتصفح.
- إعداد تصدير ثابت ونشر عبر GitHub Actions إلى GitHub Pages.

## ملاحظة

المنتجات والأسعار تجريبية، والملف الشخصي والطلبات محفوظة على الجهاز فقط. لا توجد مصادقة مستخدمين أو قاعدة بيانات أو خدمة توصيل مرتبطة بعد.
