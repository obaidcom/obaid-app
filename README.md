# متجر عبيد الإلكتروني

متجر عربي RTL مبني باستخدام التقنيات الحديثة:

- **Next.js App Router** مع TypeScript.
- **Tailwind CSS v4** للتصميم المتجاوب.
- **shadcn/ui** مع Radix UI لبناء عناصر واجهة قابلة للوصول والتخصيص.
- **Framer Motion** للحركات والتفاعلات الدقيقة.
- **Lucide React** للأيقونات.
- **next-themes** لدعم الوضع الداكن والفاتح تلقائياً.
- **Cairo** للخط العربي.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## الواجهة

- بحث وتصنيفات للمنتجات.
- سلة مشتريات تفاعلية مع التحكم بالكميات والحذف.
- المفضلة وملف شخصي وواجهة إتمام طلب تجريبية.
- حركات وانتقالات ناعمة وتخطيط متجاوب للهاتف والكمبيوتر.
- مكونات UI قابلة لإعادة الاستخدام: Button, Card, Input, Badge, Dialog, Sheet, Avatar, Separator, Label, Skeleton, Dropdown Menu, Switch, Tabs.

## التخزين والطلبات

السلة والملف الشخصي والمفضلة والطلبات في النسخة الحالية تجريبية ومحفوظة محلياً في المتصفح. لم يتم ربط تسجيل دخول حقيقي أو قاعدة بيانات أو بوابة دفع أو خدمة شحن بعد.

## التحويل إلى تطبيق

تم إعداد المشروع كتطبيق ويب حديث أولاً. يمكن لاحقاً إضافة Capacitor لتحويله إلى Android APK بعد استقرار الواجهة واختبار البناء.
