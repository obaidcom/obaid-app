# متجر عبيد الإلكتروني

واجهة عربية متجاوبة لمتجر عبيد الإلكتروني.

## تشغيل المعاينة

افتح `index.html` مباشرة أو فعّل GitHub Pages من إعدادات المستودع مع اختيار فرع `main` ومجلد الجذر.

## ما تحتويه النسخة الحالية

- الصفحة الرئيسية والأقسام والمنتجات التجريبية.
- البحث عن المنتجات وسلة مشتريات محلية.
- نموذج تجريبي لإتمام الطلب والدفع عند الاستلام.
- صفحة حساب تعرض الطلبات المحفوظة محلياً على الجهاز.

## تنبيه

هذه واجهة أولية. الطلبات والحسابات لا تُرسل إلى خادم بعد، وتحتاج المرحلة التالية إلى قاعدة بيانات ومصادقة ولوحة إدارة حقيقية.
